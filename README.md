# 🗄️ SQL Retail & Sales Data Analysis Project

## 📖 Overview
This project was completed as part of a **Data Technician Bootcamp** and showcases the application of **SQL** to analyse retail and sales data. The project focused on querying relational databases to retrieve, organise, and interpret data, helping to uncover valuable business insights and support data-driven decision-making.

## 🚀 Skills Demonstrated

### 🔍 Data Retrieval & Filtering
- Used `SELECT` statements to extract relevant datasets.
- Applied `WHERE` clauses to filter records based on specific business requirements.
- Utilised operators such as `IN`, `BETWEEN`, `LIKE`, `AND`, and `OR` to refine query results.

### 📊 Data Sorting & Organisation
- Used `ORDER BY` to sort records in both ascending and descending order.
- Organised customer, product, sales, and order data for reporting purposes.

### 📈 Data Aggregation & Insights
- Created summary reports using:
  - `COUNT()`
  - `SUM()`
  - `AVG()`
- Applied `GROUP BY` to analyse trends and patterns within datasets.
- Generated insights such as:
  - Product counts by category
  - Total quantities sold
  - Customer and geographical summaries

### 🔗 Database Relationships & JOINs
- Combined data from multiple tables using SQL joins.
- Worked with:
  - `INNER JOIN`
  - `LEFT JOIN`
  - `RIGHT JOIN`
  - `FULL JOIN`
  - `CROSS JOIN`
- Linked customers, orders, products, suppliers, categories, and employees to produce comprehensive business reports.

## 💼 Business Analysis Outcomes
Through SQL querying and data exploration, I was able to:

 Identify high-value products and sales opportunities  
 Analyse customer locations for targeted marketing campaigns  
 Generate inventory and supplier reports  
 Investigate order history and purchasing behaviour  
 Produce category-level sales summaries using grouped data  
 Combine multiple datasets to support supply chain and sales reporting

## 🛠️ Technologies Used
- SQL
- MySQL Workbench
- Northwind Database
- Relational Database Design Principles

## 🎯 What I Learned
This project strengthened my understanding of relational databases and SQL best practices. By writing complex queries, performing table joins, filtering datasets, and creating aggregated reports, I gained hands-on experience in transforming raw retail and sales data into meaningful business insights.
